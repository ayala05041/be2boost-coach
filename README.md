# be2boost | מאמן שיחות מכירה: מדריך הפעלה

אפליקציית אינטרנט: נציגה נכנסת עם סיסמת צוות, מעלה הקלטה (או מדביקה תמלול) ומקבלת דוח בעיצוב be2boost. לא נדרש חשבון Claude. שום הקלטה או תמלול לא נשמרים בשרת.

## מה בחבילה
- `server.js` שרת (ללא תלויות). `prompt.js` הרובריקה והכללים (כאן מעדכנים כללים חדשים). `public/index.html` הדף הממותג.

## שלבי הפעלה (כ-40 דקות)
1. **מפתח Claude:** console.anthropic.com. הוסיפי אמצעי תשלום, צרי API key, והגדירי תקרת הוצאה חודשית.
2. **מפתח תמלול:** platform.openai.com. צרי API key והגדירי תקרת הוצאה.
3. **GitHub:** צרי חשבון, צרי repository פרטי (Private) והעלי אליו את כל קבצי התיקייה.
4. **אחסון באינטרנט:** באתר render.com (או Railway). בחרי New > Web Service, חברי את ה-repository.
   - Runtime: Node. Build Command: ריק או `npm install`. Start Command: `node server.js`.
5. **משתני סביבה (Environment Variables):**
   - `ANTHROPIC_API_KEY` = מפתח Claude
   - `OPENAI_API_KEY` = מפתח התמלול
   - `APP_PASSWORD` = סיסמת צוות ארוכה שתמסרי לנציגות
   - אופציונלי: `CLAUDE_MODEL` (ברירת מחדל claude-sonnet-5-5), `TRANSCRIBE_MODEL` (ברירת מחדל whisper-1)
6. אחרי הפרסום תקבלי כתובת. פתחי אותה, היכנסי עם הסיסמה והעלי את הקלטת רחל. הציון אמור להיות קרוב ל-64.
7. אפשר לחבר כתובת משלכם (למשל coach.be2boost.com) בהגדרות Domain של השירות.

שמות הכפתורים בפלטפורמות משתנים מעת לעת. אם משהו לא תואם, חפשי את המקבילה או פני למפתח/ת.

## חשוב לדעת
- **גודל קובץ:** עד 24MB (מגבלת שירות התמלול). קובץ mp3 של שעה הוא בדרך כלל קטן מזה. wav צריך להמיר ל-mp3.
- **איכות עברית:** לא נבדקה בפועל. הריצי שיחות אמיתיות וקראי את התמלול. אם האיכות חלשה, אפשר להחליף ספק תמלול בשינוי בפונקציה `transcribe` ב-`server.js`.
- **הפרדת דוברים:** התמלול אינו מסומן לדוברים. Claude מסיק מי הנציגה מההקשר ומציין זאת בדוח.
- **אינטונציה ושתיקות:** לא נבדקות מתמלול.
- **אין היסטוריה או מעקב התקדמות.** אפשר להוסיף מסד נתונים בשלב הבא.
- **סיסמה אחת לכולן:** כל נציגה עם אותה סיסמה. לסיסמה אישית ולהרשאות ("כל אחת רואה רק את שלה") צריך להרחיב.
- **פרטיות:** ההקלטה נשלחת לספק התמלול והתמלול ל-Anthropic. בדקי את תנאי הטיפול במידע שלהם, ועם איש מקצוע משפטי: הודעה ללקוח על הקלטה, ושמירה. זו אינה ייעוץ משפטי.
- **הוצאות:** כל ניתוח עולה סכום קטן לפי שימוש. עקבי בלוחות הבקרה של שני הספקים.
